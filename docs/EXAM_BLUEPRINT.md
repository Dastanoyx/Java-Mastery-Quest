## 2. Exam format as configured

```yaml
exam:
  code: 1Z0-831
  questions: 50
  durationMinutes: 120
  passingPercent: 68
  personalReadyTargetPercent: 80   # deliberately above the pass mark
  formats: [single, multi]          # only these appear in strict exam mode
```

**Question-format rules applied by the app (from the 2026-10-13 sources):**

- Multiple-response questions state how many answers to choose ("Choose two."). The app shows "Choose N"
  on every multi-select question in every mode, including strict exams — so a learner never practises a
  harder format than the real one, and never an easier one.
- Scoring is all-or-nothing per question: a multi-select answer is correct only when exactly the right set
  is chosen. The app's scorer has always worked this way (`domain/scoring.ts`), so mock percentages are
  comparable with the real exam's.

Oracle does **not** publish per-domain weights for this exam. Full mock exams therefore distribute
questions proportionally to the number of objectives per domain (with a minimum of 3 per domain). This is
an app assumption, documented in `docs/DECISIONS.md` (D-007).

## 3. Objective checklist

Legend — **Basis**: `830` = carried over from the official 1Z0-830 (Java SE 21) objective; `J25` = Java 22–25
final feature added because secondary sources list it as in scope; **Coverage** columns are generated by
`npm run content:report` (see `docs/COVERAGE_REPORT.md`).

| ID | Objective (paraphrased) | Basis |
|---|---|---|
| D1.1 | Use primitives and wrapper classes; evaluate arithmetic and boolean expressions using the Math API, operator precedence, type conversion, promotion and casting | 830 |
| D1.2 | Manipulate text, including text blocks, using `String` and `StringBuilder` | 830 |
| D1.3 | Work with date, time, duration, period, instant and time-zone objects, including daylight-saving transitions, using the Date-Time API | 830 |

| ID | Objective | Basis |

## 4. Java 25 scope decisions

| Feature | JDK status in 25 | In app scope? |
|---|---|---|
| Unnamed variables & patterns (JEP 456) | Final since 22 | Yes — D3.4, D4.1, D2.1 |
| Launch multi-file source programs (JEP 458) | Final since 22 | Yes — D7.2 |
| Stream Gatherers (JEP 485) | Final since 24 | Yes — D6.2 |
| Scoped Values (JEP 506) | Final in 25 | Yes — D8.1 |
| Module import declarations (JEP 511) | Final in 25 | Yes — D7.1 |
| Compact source files & instance main methods (JEP 512) | Final in 25 | Yes — D7.2 |
| Flexible constructor bodies (JEP 513) | Final in 25 | Yes — D3.2 |
| Structured Concurrency (JEP 505) | **Preview** in 25 | Supplementary only (exams don't test preview features) |
| Primitive types in patterns (JEP 507) | **Preview** in 25 | Supplementary only |
| Stable values (JEP 502) | **Preview** in 25 | Not covered |
